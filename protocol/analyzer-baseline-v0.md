# Circomspect baseline v0

Build official Trail of Bits source at 50010b623ed4f3bff9d1b0363cfe952385b47af3 with its Cargo.lock. Local Docker maximum four CPUs/6GiB, 600-second build-and-analysis bound. Analyze original and repaired top-level circuits with INFO reporting and library path. Preserve source and tool hashes, logs and SARIF. Exit status alone is not a vulnerability outcome. Unsupported syntax or build failures are not misses. This is one static baseline, not a comparison with zkFuzz or all prior work.
