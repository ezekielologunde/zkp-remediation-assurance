# Frozen bounded corpus expansion

Date: 2026-10-07 America/Chicago. This is a prospective extension of an exploratory pilot, not retrospective preregistration. PIRANHAS and TrustBOM outcomes are already known. zkSBOM was previously inspected statically. Record this selection bias.

Population: publicly accessible research papers dated 2024 through 2026-10-07 whose central application is zero-knowledge remote attestation or confidential SBOM queries/compliance. Seed papers from the existing literature audit: zRA, PIRANHAS, zkSBOM, VeriSBOM, TrustBOM. Screen ALL five, including negative/no-mismatch cases. This is a purposive five-paper sample, not a systematic census or prevalence sample. No extra domains are added after observing outcomes.

Eligibility for source analysis: author-linked public implementation and identifiable version. Eligibility for executable controls: documented minimal local example, source-visible expected statement, no private keys/accounts or live deployment required. Artifact unavailable, dependency/build failure, unsupported feature, and unexplored cases remain separate outcomes. Do not label an artifact generally correct because limited controls pass.

Discovery: inspect paper and official repository for links, plus targeted title/artifact searches. If no link found, record not located in this search, not nonexistent. Freeze source commit and file hashes before adapter execution. No public issues/author contact. Never run deployments or attack live targets.

Unit: research system, not backend, mutation, or proof. zRA is an explicit intellectual predecessor of PIRANHAS; record related lineage rather than treating them as independent corroboration. Benchmarks and application handlers are separate layers. Code similarities may further reduce independence.

Per-system contract ledger: claimed statement; public inputs; witness; authority for expected root/key/policy/challenge; actual verifier call; honest proof outcome; applicable one-field negative controls; assumptions and limits; supported analyzer and execution status.

Budget: first pass source/contract assessment for all five; minimal local positive and negative controls for newly eligible artifacts, 15 minutes per individual build/proof command with explicit timeout, preserve failures. Prior executions retained. Do not substitute a simpler Merkle mode for a zero-knowledge set and claim zkSBOM's ZK system reproduced.

Decision: a new finding requires a documented requirement, isolated reproducible mismatch, and evidence that it is not merely an acknowledged assumption. Repairs and standard authenticated manifests are baselines, not novelty. If this corpus supplies only one familiar implementation omission, retain a technical audit rather than claiming a novel detector or journal-ready contribution.
